# FarmBuddy — Frontend (Next.js)

Next.js 16 (App Router) + React 19 + TypeScript frontend application for FarmBuddy.

## Setup & Running

```bash
# 1. Install dependencies
npm install

# 2. Start development server on port 3000
npm run dev
```

The frontend connects to the Django backend at `http://127.0.0.1:8000/api/` as configured in `.env.local`.
